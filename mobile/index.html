ORYX Marketplace — the approved design

The customer and merchant application (apps/mobile), built to the two mockups the owner approved. Every element below is a real React Native component captured from the running app, not a screenshot pasted into a page.

How to read the comparison sheets. Each sheet puts the approved mockup on the left and the running app on the right, at a matched height. The two reference files are named the wrong way round — ORYX_Splash_Reference.jpg carries the marketplace homepage and ORYX_Homepage_Reference.jpg carries the hero-only splash — so the implementation follows the content. That is recorded in apps/mobile/design-reference/README.md.
The judge of the match is the owner, not this page. The build environment has no working vision, so the comparison was made programmatically — OCR for the copy and section order, luminance and edge profiles for the vertical composition, bright-pixel boxes for the logo, and the rendered DOM for what is actually drawn. No pixel-match is claimed; these sheets exist so you can judge it.
