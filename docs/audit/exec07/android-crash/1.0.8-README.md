## The 11 "FATAL EXCEPTION" lines in logcat are not ours

`grep -B3 "FATAL EXCEPTION" logcat | grep -c oryx` returns **0**. The affected
processes are:

```
IN SYSTEM PROCESS
com.android.networkstack.process
com.android.phone
com.android.systemui
com.google.android.apps.nexuslauncher
com.google.android.as
com.google.android.gms
com.google.android.gms.persistent
com.google.android.googlequicksearchbox
com.google.android.permissioncontroller
```

The first line is the root: `Lost network stack. This is not the root cause of
any issue, it is a side effect of a crash that happened earlier.` The emulator's
whole system server died under CPU starvation without KVM, and every Google
system process followed it. Our app kept its process and its React instance.

## Screenshots are black, and why

`screencap` returns black frames on this emulator: the app's surfaces exist in
SurfaceFlinger (11 entries) and its windows are registered (7), and the activity
is `topResumedActivity` with `visible=true`, but the swiftshader compositor does
not paint without hardware acceleration.

This means **the visual appearance is not verified**. The layout is verified
structurally, through the view hierarchy. A screenshot from a real phone, or from
an emulator with KVM, is still needed before the visual design can be called
confirmed.
