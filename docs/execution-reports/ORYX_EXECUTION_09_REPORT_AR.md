## 2. الأعمال المنجزة

### 2.1 الموارد البشرية — تعديل وحذف موقع العمل (جديد)

كان إنشاء مواقع العمل (مواقع تحديد الحضور) وعرضها متاحاً، لكن بلا تعديل أو حذف.
أُضيف:

- `DELETE /api/v1/hr/work-sites/:id` — يحل نطاق شركة المستدعي، ويعيد 404 لموقع
  خارج نطاقه، ويحذفه ويسجّل تدقيقاً.
- `api.deleteWorkSite(id)` في عميل الإدارة.
- زرّا **تعديل** و**حذف** في كل صف موقع عمل ضمن تبويب سياسة الموارد البشرية،
  محجوبان خلف صلاحية إدارة مواقع العمل (من لا يملكها لا يرى العمود أصلاً).
- نص تأكيد ثنائي اللغة؛ الحذف يستخدم `window.confirm` باسم الموقع المحلي.

الالتزام: `42ce026 feat(hr): edit and delete work sites`

### 2.2 فواتير المبيعات — مطابقة النموذج المعتمد

المطبوعة تعيد إنتاج `oryx 22.pdf`: شعار ORYX الرسمي ومعلومات الشركة بجانبه،
والمجموع الفرعي **قبل** الضريبة، والخصومات منفصلة، ومبلغ ضريبة القيمة المضافة
منفصلاً، والإجمالي النهائي **شاملاً** الضريبة، مع تفاصيل السعر لكل سطر.

```
 المجموع قبل الضريبة   35.200 BD
 ضريبة 10%              3.520 BD
 الخصم                  1.720 BD
 الإجمالي (شامل)       37.000 BD
```

رمز التحقق QR هو رمز **المستند الصادر نفسه** المقروء من السجل، لذا تحمل إعادة
الطباعة وملف PDF الصادر الرمز ذاته. المستند غير الصادر لا يطبع رمزاً بدل رمز
لا يُقرأ.

الفاتورة المُعاد توليدها **مطابقة بايت-ببايت** للمرجع المعتمد
(`md5 3cf0c6bf853b86a0402ae3f358505bc0`)، والرمز المُضمَّن يُفكّ إلى رابط تحقق
حيّ. دقة الدينار البحريني (ثلاث خانات) ونسبة الضريبة المطبَّقة محفوظتان عبر
دوال المال المشتركة (`toMinor`، `basisPointsOfMinor`).

**الدليل:** `e09-invoice-ref-left_vs-rend-right.png` (المرجع يساراً، المُنتَج
يميناً) وملف `rendered-invoice.pdf`.

### 2.3 النوافذ المنبثقة والسمات — مُتحقَّق

الطبقة الخلفية تغطي واجهة التطبيق (`z-index: 60` فوق الترويسة `40` والقائمة
الجانبية `30`)، والنافذة لها سطح معتم، و**السمة الفاتحة** تعطي سطحاً فاتحاً
(`--surface: #ffffff`) وليس الكحلي. **السمة الداكنة لم تتغير.** العربية RTL
والإنجليزية LTR تعملان بشكل صحيح.

### 2.4 الموارد البشرية — المستندات والهاتف وتاريخ الانتهاء (مُتحقَّق)

رفع مستندات الموظفين وإدارتها يعمل: مربع الاختيار «سري» في `FormData` يُرسل
نصاً `"true"` وكان `@IsBoolean()` يرفضه بخطأ 400؛ أُضيف `ToBoolean()` للتحويل
قبل التحقق. رقم الهاتف الإضافي وتاريخ انتهاء التوظيف يُحفظان. المعاينة والتنزيل
يبثّان البايتات المخزّنة وفق صلاحية المستند السري.

### 2.5 إدارة الفروع (مُتحقَّق)

نموذجا الإنشاء والتعديل يحملان الحقول نفسها بالترتيب نفسه (الرمز، الاسم عربي/
إنجليزي، المدينة، الدولة، العنوان، الهاتف، المنطقة الزمنية) والخادم يحفظها كلها.

### 2.6 طلبات الإجازة (مُتحقَّق)

التاريخ البسيط `YYYY-MM-DD` الصادر من `<input type="date">` يُحوّل إلى ISO 8601
عبر المزيّن `NormaliseIsoDate` قبل أن يتحقق `@IsISO8601()`، لذا تعمل عمليات
الإنشاء والتعديل والموافقة دون رفض.

### 2.7 شجرة الحسابات (مُتحقَّق)

تعديل نوع الحساب والحساب الأب يُحفظان. قائمة الحساب الأب تستبعد الحساب نفسه
وكل أحفاده، فلا تعرض الواجهة أبداً نقلاً يُنشئ دورة؛ والخادم يرفض هذا النقل
ويرفض تغيير نوع حساب له أبناء.

### 2.8 فحوصات السيارات (مُتحقَّق)

تعرض الخدمة سعر الأساس ونسبة الضريبة ومبلغ الضريبة والإجمالي شاملاً الضريبة في
معاينة حيّة وفي القائمة، وتدعم صورة، ويحمل نموذج الحجز الفرع ومنتقي التاريخ
والوقت. حقول التاريخ/الوقت مُكبَّرة عبر `.oryx-input--date` ومؤشر تقويم مُنسَّق
`::-webkit-calendar-picker-indicator`.

## 5. ملاحظات وأعمال متبقية

- لم يتم النشر إلى الإنتاج؛ يلزم تفويض صريح من المالك للنشر.
- عند النشر: اضبط `DOCUMENT_VERIFY_BASE_URL` على الأصل العام
  (`https://oryxbhr.com`) وإلا بقي الرمز المطبوع يشير إلى أصل محلي/معاينة.
- طلب السحب #12 (نسخة أقدم من ضريبة الفحص) يُستبدل بهذه الحزمة. طلب السحب #14
  يتداخل في `hr/page.tsx` مع نسخة أحدث وأشمل هنا؛ يُنصح بدمج #13 أولاً ثم إغلاق #14.
- تشغيل مجموعات اختبار الواجهة يتطلب رفع حدود التحديد على API
  (`AUTH_THROTTLE_LIMIT` و`REFRESH_THROTTLE_LIMIT`)، وإلا تظهر أخطاء 429 تبدو
  كعدم استقرار.
