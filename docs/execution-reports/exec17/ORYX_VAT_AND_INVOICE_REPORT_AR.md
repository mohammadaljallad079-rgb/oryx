## 1) ملخص تنفيذي

كانت المنصّة تُهيّئ كل المستأجرين على نسبة ضريبة قيمة مضافة افتراضية **15%**
بينما تعليق التهيئة يقول إنها «النسبة القياسية في البحرين». النسبة القانونية
القياسية في مملكة البحرين هي **10%**، والفاتورة المعتمدة `oryx 22.pdf` تطبع
`VAT 10%` في كل سطر و`Tax 10%` في ملخّص المجاميع.

تم تصحيح هذا الخلل الجذري عبر:
- تغيير الافتراضي في قاعدة البيانات إلى `1000` نقطة أساس (10%).
- جعل صفّ `VAT10` المُهيّأ هو الافتراضي للمستأجر مع بقاء `VAT15` قابلًا للاختيار.
- نقل كتالوج المنتجات المُهيّأ (24 صنفًا) وخدمات الفحص إلى 10%.
- إضافة ترحيل (migration) يعالج المستأجرين الحاليين دون الإخلال بقيد
  «افتراضي واحد لكل مستأجر».
- جعل نماذج البيع والشراء تقرأ نسبة الضريبة الافتراضية من المستأجر بدل قيمة
  ثابتة، لتتطابق الواجهة والـ API والـ PDF.

**النتيجة:** لا فرق بين الواجهة والـ API والـ PDF، والفاتورة المُصدرة تطابق
المرجع المعتمد في بنية المجاميع ونسبة الضريبة.

### دليل حسابي فعلي (من الـ API نفسه)

فاتورة اختبارية بثلاثة أسطر بضريبة 10%:

```
subtotal 76800   discount 0   tax 7680   total 84480   | reconciles: true
```

أي: `76800 − 0 + 7680 = 84480` — متوازن تمامًا، والضريبة = 10% بالضبط.

### دليل رمز QR من داخل ملف PDF

تم استخراج صورة رمز QR من ملف PDF فعلي وفكّ ترميزه، فأنتج:

```
https://oryxbhr.com/verify/oX0zGQIF9OVkschLbbgTpXSCyAZ05DPByiwrJn0vaOo
```

وعند طلب نقطة التحقّق العامة `/documents/verify/:token` أعادت:

```json
{ "found": true, "document": { "status": "VALID", "type": "SALES_INVOICE",
  "documentNumber": "S00158" } }
```

أي أن الرمز **حقيقي وقابل للمسح**، ويفتح صفحة تحقّق عامة بدون تسجيل دخول.

> ملاحظة أمانة: في بيئة التطوير المحلية يكون رابط الرمز `localhost:3002` لأن
> متغيّر `DOCUMENT_VERIFY_BASE_URL` غير مضبوط على الإنتاج. عند ضبطه على
> `https://oryxbhr.com` (كما في تشغيل الإنتاج) يُطبع الرابط الصحيح، وهذا ما
> تم التحقق منه أعلاه.
